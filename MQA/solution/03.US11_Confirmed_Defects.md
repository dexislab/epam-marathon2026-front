# Manual QA #7 – US11: Guest Reservation and Menu View

## 03. Confirmed defects

### Defect ID: US11-DEF-01
### Title: Unavailable menu items remain selectable for pre-order

| Field | Value |
|---|---|
| Severity | High |
| Priority | High |
| Environment | Screenshot validation, browser view |
| Preconditions | Guest is on menu page; at least one menu item is marked unavailable |
| Steps to reproduce | 1. Open the menu page. 2. Find a card marked “Out of Stock”. 3. Click the “Pre-Order” button on that card. |
| Expected result | Unavailable items must be clearly marked as unavailable and must not be selectable or added to the cart. |
| Actual result | The card is labeled “Out of Stock”, but the “Pre-Order” button remains active and clickable. |
| Requirement reference | AC4: “Items currently marked 'On Stop' are clearly indicated as unavailable and cannot be selected or added to the cart.” |
| Evidence | Visible in the implementation screenshot: cards with the unavailable label still contain an active Pre-Order action. |
| Result | Fail |

### Justification
- the dish card is marked unavailable
- the pre-order action is still active
- the requirement explicitly says unavailable items cannot be selected or added

This is a direct mismatch between requirement and implementation.
