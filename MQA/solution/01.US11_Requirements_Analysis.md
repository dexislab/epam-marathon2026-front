# Manual QA #7 – US11: Guest Reservation and Menu View

## 01. Requirements analysis

### User Story
As a Guest, I want to see the full restaurant menu, so that
I know what options are available and can decide what to choose.

### Preconditions
- Guest has successfully joined the session (US_G10)
- Parent reservation / group status is in Created or Reserved state

### Acceptance Criteria
1. Guest can view the full restaurant menu structured logically by category.
2. Each menu item must clearly display:
   - name
   - price
   - serving size in grams
   - image
   - current availability status
3. Guest can add an available dish directly to their personal subcart using
   a clear action button.
4. Items currently marked as unavailable must be clearly indicated and cannot
   be selected or added to the cart.
5. The menu reflects current data when the guest opens or refreshes the screen.

### Requirement gaps / clarification points
The following points are not clearly defined in the User Story
and should be additionally clarified by product or BA:

- “Full menu” scope is unclear:
  - all restaurant menu items or only reservation-specific items
- Category ordering and empty-category behavior are not defined
- Price format and currency are not defined
- Missing data / invalid data behavior for image and serving size is not defined
- Availability states beyond “On Stop” / “Out of Stock” are not defined
- Empty state / loading state / error state are not specified
- The behavior for duplicate add-clicks or quantity updates is not defined
- Refresh timing and stale-data behavior are not defined
- Accessibility and responsive behavior are not defined
