11_Guest Viewing Reservation Menu** 

|**Epic**|**Order Management**|
|---|---|
|US name|Guest Reservation and Menu View|
|Role|Guest|
|Description|As a Guest, I want to see the full restaurant menu, so that I know what options are available and can decide what to choose.|



## **Pre-conditions:** 

Guest has successfully joined the session (US_G10). The parent reservation or group session status is in Created/"Reserved". 

## **Acceptance Criteria (AC):** 

1.  The Guest can view the full restaurant menu structured logically by category (e.g., Appetizers, Main Course, Desserts). 2.  Each menu item must clearly display name, price, serving size in grams, image and current availability status. 

3.  The Guest can add an available dish directly to their personal subcart by interacting with a clear action button (e.g., "Pre-order" ) 

4.  Items currently marked "On Stop" are clearly indicated as unavailable and cannot be selected or added to the cart. 5.  The menu reflects the current data at the time the Guest opens or refreshes the screen.
